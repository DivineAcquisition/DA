# Roofing VSL: recording deck

These are the visuals for the **Roofing VSL Script** (draft of October 9, 2026). That script is the video for the Lead Leak Audit page at `acq.divineacquisition.io/roofing`. The deck uses the page's own look: the `#07070b` page with a purple glow, Plus Jakarta Sans headlines with italic `#c3b6fe` accents, Inter Display body text, black cards, and the purple gradient button.

Every word on screen comes from the script or from its claims table. The deck has no dashboards, no texts and no screenshots, so nothing on it could pass for proof.

## What's here

| File | What it is | Use it for |
| --- | --- | --- |
| `deck.html` | The deck. One file that works offline. | Open it in Chrome and screen-record while you talk |
| `frames/` | 1920×1080 PNGs, one per build, main-cut order | Drop them on a timeline if you edit instead of screen-recording |
| `thumbnail.png` | Plain click-to-play poster | The video thumbnail on the page (no autoplay) |
| `storyboard.png` | Every frame as a numbered thumbnail | Seeing the whole video at a glance |

## Recording with the deck

1. Open `deck.html` in Chrome and press **F** for full screen.
2. Press **P** to open the script window. Put it on your second screen, or next to your camera, and keep it out of the capture. It shows the line to say on the current frame, the next line, and a clock against the script's timestamps.
3. Start your recorder (Loom, OBS or similar) at 16:9. Press **→** when you start each new line. The script window can move the deck too.
4. Press **S** to switch to the 0:45 short cut. The deck and the script window both reset to its 9 frames.

| Key | Does |
| --- | --- |
| → · Space · Enter · click | Next build |
| ← · Backspace | Back one build |
| Home / End | First / last frame |
| P | Open the script window |
| S | Switch between the main cut (about 2:15) and the short cut (0:45) |
| F | Full screen |
| H | Show or hide the key hint |
| R (in the script window) | Restart the clock |

The bottom 180 px of every frame are left empty for burned-in captions. If you put your camera in a bubble, a top or bottom corner covers nothing important.

The script's production notes say to shoot vertical or 4:5 on your phone. This deck is for a 16:9 version, which is what the page's video slot plays. If you shoot phone-only, use the frames as cutaways in the edit.

## Before you record

The script left these items open. The deck follows the script as written, so change the template if any of them change.

- Confirm "about a minute" is the first-reply time you will build to (frame 04).
- Confirm you want your name in the opening line (frame 03).
- Confirm the audit is still 30 minutes and the install is still 14 days (frames 06, 20, 23).
- The video proposal line (frame 15) belongs in the pitch only for clients who already have a measurement tool. For a general VSL, decide whether to keep it.

## Changing the deck

The words and layout live in `scripts/roofing-vsl/deck.template.html`. Each slide's script lines are in its `.say` blocks. Rebuild with:

```sh
npm i --no-save playwright        # once; or set PLAYWRIGHT_MODULE to an existing install
node scripts/roofing-vsl/build.mjs          # deck.html, frames, thumbnail, storyboard
node scripts/roofing-vsl/build.mjs --deck   # deck.html only, no browser needed
```

The build puts the fonts (Plus Jakarta Sans and Inter Display, both under the SIL Open Font License) and the Divine Acquisition mark inside `deck.html`, so it opens with no network.
